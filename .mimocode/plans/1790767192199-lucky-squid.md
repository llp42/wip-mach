# Plan: rename `Wheel` → `HashedWheel`

## Why

Paper §6.1.2 names Scheme 6 “Hash Table with Unsorted Lists in each
Bucket”; the abstract calls the structure a **timing wheel** with the
interval “hashed into a slot”. `HashedWheel` is the short, paper-faithful
name: it keeps the wheel metaphor and marks the hash that distinguishes
Scheme 6 from Scheme 4. Nothing outside `crates/clock` imports `Wheel`
yet (uncommitted work), so the rename is cheap now.

Settled choices: type **`HashedWheel`**, **full crate rename** (type,
module/file, `Callout::wheel()`, tests, benches, README/AGENTS/ADRs/PLAN).

## Rename map

| Before | After |
|---|---|
| `struct Wheel<P>` | `struct HashedWheel<P>` |
| `src/wheel.rs`, `mod wheel` | `src/hashed_wheel.rs`, `mod hashed_wheel` |
| `pub use wheel::{TickSource, Wheel}` | `pub use hashed_wheel::{HashedWheel, TickSource}` |
| `Callout::wheel()` | `Callout::hashed_wheel()` |
| test/bench aliases `TestWheel`, `BenchWheel`, `STATIC_WHEEL`, `leaked_wheel` | `TestHashedWheel`, `BenchHashedWheel`, `STATIC_HASHED_WHEEL`, `leaked_hashed_wheel` (locals may keep `wheel` as the English noun where the type is clear) |
| docs/ADR type refs `Wheel`, `Wheel::new`, … | `HashedWheel`, `HashedWheel::new`, … |
| ADR `0005-wheel-owns-a-critical-lock.md` | `0005-hashed-wheel-owns-a-critical-lock.md` (title matches) |

**Prose that stays “wheel(s)”:** the English noun in narrative (“one
independent wheel”, “the wheels”, paper title *Hashed and Hierarchical
Timing Wheels*). Only the **type/module/method identifiers** change.
`TickSource`, `Callout`, `Record`, `Stats`, `poll`/`advance` are unchanged.

**Do not edit:** `varghese-lauck-1987-timing-wheels.md` (paper
transcription), `PLAN-02.md` type sketches (historical rejected plan —
optional one-line note that `Wheel` there is now `HashedWheel` is
enough, or leave as-is).
